# Life in LA — розмовний курс

```
life-in-la/
├── index.html                  головна сторінка курсу (кімната, телефон, мапа, журнал…)
├── episodes/
│   └── episode-01/             Епізод 1 «Arrival»
│       ├── episode-01.js       сцени, діалоги, міні-ігри, збереження
│       ├── episode-01.css      вигляд епізоду
│       └── photos/             фото для сцен (.webp) + README з промптами
└── supabase/
    └── 01-episode-01-story.sql міграція бази (запустити один раз)
```

## Як викласти

1. Залий усю папку в репозиторій GitHub Pages **з тією ж структурою** — `index.html` у корені.
2. Supabase → SQL Editor → встав вміст `supabase/01-episode-01-story.sql` → Run.
   Безпечно запускати повторно; нічого не видаляє.
3. Фото — за бажанням: поклади `.webp` з назвами з `episodes/episode-01/photos/README.md`
   у ту саму папку. Поки їх немає, сцени показуються намальованими.

## Перегляд без входу

`index.html?preview=1` — режим перегляду: прогрес зберігається тільки в цьому браузері,
записи учнів у базі не чіпаються.

## Наступні епізоди

Кожен новий епізод — своя папка `episodes/episode-02/` з такими ж файлами,
а міграції бази, якщо знадобляться, — наступні номери в `supabase/` (`02-…sql`).
